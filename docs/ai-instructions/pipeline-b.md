# Pipeline B instructions

## Purpose
Pipeline B covers AI-assisted media creation, including voice generation and video generation.

## Workflow expectations
- Treat Pipeline B as a follow-on workflow to the content pipeline rather than a standalone system.
- Keep outputs aligned with the channel voice, audience, and factual standards.
- Make sure generated assets are reviewed for tone, clarity, and compliance with the channel's financial-disclaimer requirements.

## Voice generation
- Generate voiceover content that matches the approved script and channel tone.
- Keep pacing and phrasing natural and conversational.
- Preserve the intended meaning of the script without adding unsupported claims.

## Video generation
- Generate visual assets that support the message rather than distract from it.
- Keep visuals aligned with the script structure and the audience's expectations.
- Review generated media for factual accuracy, clarity, and consistency with the brand voice.

## Review guidance
- Confirm that any generated content still satisfies the channel's disclaimers and time-sensitive-data requirements.
- If a generated asset introduces ambiguity, ask for a clarification or revision before moving forward.
