# Project context instructions

## Project scope
- This repository supports a content pipeline for a real estate and lending education channel.
- The work spans research, scripting, repurposing, scheduling, analytics, and content organization.

## Content operating model
- The channel uses a mix of educational explainers, news and commentary, and case studies.
- Content should be practical and useful for an audience that has already done some research and is considering a real estate decision.

## Working style preferences
- Explain tools and steps clearly the first time, but avoid over-explaining once the workflow is understood.
- Before running commands or making changes, briefly explain what will be done and why.
- If a decision has meaningful tradeoffs or could cause side effects, pause and ask before proceeding.
- Prefer to review scripts or content before publishing or scheduling.
- Show intermediate output so the user can review or refine it.
- When possible, provide a place to jump in and learn from the process.

## File organization expectations
- Use the content directory structure defined by the environment variables.
- Scripts should go into the scripts directory.
- Repurposed content should go into the repurposed content directory.
- Analytics reports should go into the analytics directory.
- Ideas should be added to the backlog rather than overwriting it.

## Known corrections and open questions
- Keep track of known factual issues and update guidance when corrections are learned.
- Track unresolved decisions such as posting cadence, monetization, and whether to appear on camera.
